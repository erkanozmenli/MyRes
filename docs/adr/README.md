# Architecture Decision Records (ADR)

This folder contains architecture decisions that affect the entire solution.

## Purpose

ADRs document important architectural decisions and their rationale.

They help the team understand:

* Why a decision was made
* Alternatives that were considered
* Expected consequences
* Historical context

## ADR Format

Each ADR should contain:

* Status
* Context
* Decision
* Consequences

## Status Values

* Proposed
* Accepted
* Superseded
* Deprecated

## Naming Convention

0001-decision-name.md
0002-another-decision.md

The numbering should be sequential and immutable.
